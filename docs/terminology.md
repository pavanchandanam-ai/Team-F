# Project Terminology Guide

## 1. Purpose

This document standardizes the terminology used across the Enterprise RAG Assistant project.

The goal is to provide a common reference for frontend developers, backend developers, and contributors and to reduce confusion caused by different terms being used for the same project concepts.

This guide covers the terminology used in:

- API models
- Frontend and backend communication
- RAG components
- Authentication and authorization
- Document processing
- Retrieval
- User roles
- Departments
- API endpoints
